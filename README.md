# STUDY-CRAFT

STUDY-CRAFT is an AI-powered study kit generator designed to make learning simpler, smarter, and more effective. It transforms uploaded study materials into structured learning resources, helping students understand concepts, practice questions, and revise efficiently in one place.

## Features

- **Study Material Upload** — Upload study documents and learning materials for AI-powered analysis.
- **AI-Powered Content Analysis** — Extracts important information and identifies key topics from uploaded materials.
- **Key Concepts** — Generates 3–5 core concepts with simple, easy-to-understand explanations.
- **Multiple-Choice Questions** — Creates MCQs with four answer options, correct answers, and explanations.
- **Short-Answer Questions** — Generates questions with sample high-scoring answers.
- **Conceptual Application Questions** — Tests understanding through practical, real-world scenarios.
- **Interactive Flashcards** — Creates 5–10 question-and-answer flashcards for active recall and revision.
- **Difficulty Selection** — Supports Easy, Medium, and Hard difficulty levels.
- **Organized Study Kit** — Presents generated concepts, questions, and flashcards in a structured layout.
- **Source-Based Generation** — Keeps generated study content grounded in the uploaded material.
- **Modern Dark UI** — Provides a clean, responsive interface designed for a focused study experience.

## How It Works

1. **Upload:** The student uploads their study material.
2. **Select:** The student chooses the preferred difficulty level.
3. **Analyze:** Gemini AI processes the uploaded content and identifies important concepts.
4. **Generate:** STUDYCRAFT creates summaries, practice questions, and flashcards based on the material.
5. **Study:** The student uses the generated resources to understand, test, and revise the topic.

## Tech Stack

- **Frontend:** React, TypeScript
- **Styling:** CSS
- **AI Integration:** Google Gemini API
- **Development Environment:** Google AI Studio

## Project Goal

STUDYCRAFT aims to bring concept learning, practice, and revision together in one AI-powered platform, making study sessions more focused, interactive, and productive.
